DO INTERIOR AO HOME OFFICE - ETAPA 1: API DE CHECKOUT DE TESTE

1. Abra https://github.com/ednardoxavier/do-interior-ao-home-office
2. Clique em Add file > Upload files.
3. Arraste a PASTA api (ou o arquivo create-checkout.js para uma pasta api criada no GitHub).
   O destino obrigatório é api/create-checkout.js (não na raiz).
4. Clique em Commit changes na branch main.
5. Aguarde a Vercel publicar o novo deploy.
6. Acesse https://do-interior-ao-home-office.vercel.app/api/create-checkout
   A resposta esperada ao abrir pelo navegador é erro 405, porque a rota aceita apenas POST.

ATENÇÃO:
- Esta API só funciona com token de TESTE (prefixo TEST-).
- Não habilita pagamentos reais nem entrega arquivos automaticamente.
- Não altere o botão Comprar ainda: o webhook, registro de pedidos e a entrega ainda precisam ser implementados.
- O Access Token permanece somente nas variáveis da Vercel; nunca o inclua no repositório.
